# BrislingHomepage

**NB: Repoet er public.**

Hjemmesiden til Brisling Consulting AS, hostet på [brisling.no](https://brisling.no) via GitHub Pages fra `main`.

Statisk side — `index.html` er hele nettsiden, ingen build-steg.

Siden skal være enkel og tidløs: hvem vi er, hva vi tilbyr og kontakt. Ingen navn på ansatte eller kunder,
ingen årstall og ingen kundeeksempler, så den kan stå uendret i lang tid.
